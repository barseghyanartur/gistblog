aiGrunn talk: LLM security for beginners

2026-11-13 | Tech | python, llm-security, owasp, agentic-security, aigrunn

1000+ people attended aiGrunn 2026 in Groningen. This is quite big even by Amsterdam standards.

This year I gave a talk about LLM security for beginners — the OWASP Top 10 for LLM applications and the OWASP Agentic Skills risks, with live demos: real vulnerable code and its fix for each LLM risk, and real agent attacks (credential exfiltration, a code backdoor, a sandbox escape) that the nono sandbox then blocks.

  • Slides in HTML format: https://barseghyanartur.github.io/llm-security-talk/
  • Slides in PDF-like HTML format: https://barseghyanartur.github.io/llm-security-talk/presentation.html?print-pdf
