Bring your OpenCode sessions into Claude Code

Published: Wed 30 September 2026
Updated: Mon 05 October 2026
By Artur Barseghyan

In Tech.

tags: claude-code opencode ai developer-tools

Switching between OpenCode and Claude Code often means losing your conversation history.

claude-opencode-sessions solves this. It imports OpenCode sessions for the current repository into Claude Code.

Install it from within Claude Code:

/plugin marketplace add barseghyanartur/claude-opencode-sessions
/plugin install opencode-sessions@barseghyanartur

Run:

/opencode-sessions:import

Then open:

/resume

Your imported sessions appear with an [opencode] prefix. Pick one and continue where you stopped.

The import uses no model calls and spends no tokens. It also skips sessions that have not changed.
